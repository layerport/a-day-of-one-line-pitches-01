# A Day of One-Line Pitches

One original sentence, at most 240 characters, that would convince a friend
who has never coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

> Tell it the app idea you've been carrying around in your head, and watch it
> take shape while you sip your coffee — no code, nothing to install, and if
> you don't like it, you just say so and it changes.

The pitch is 201 characters, one sentence, plain words only: the friend just
describes the idea out loud, the agent builds a first version, and changing
anything is as easy as saying so — trying it costs nothing and commits them
to nothing.

## How to run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`. To write somewhere else,
set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pitches-out1 python3 main.py
```
